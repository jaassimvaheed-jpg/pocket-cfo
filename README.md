# Pocket CFO

A private personal-finance app for an Indian expat in Saudi Arabia: Saudi (SAR) and Indian (INR) accounts, credit cards, EMIs, remittances, budgets, India tax dates and a personal + proprietorship view.

- **Open it:** https://jaassimvaheed-jpg.github.io/pocket-cfo/ — on iPhone, Safari → Share → Add to Home Screen.
- **Your data never comes here.** It is stored only on your own device (encrypted if you turn encryption on). This repository holds only the app's code.
- **Backups:** Settings → Encrypted backup → Save to Files.
